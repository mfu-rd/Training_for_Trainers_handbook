# ประกาศสำคัญ

> รายการประกาศ เรียงจากล่าสุดไปเก่าสุด — อัปเดตเมื่อมีการเปลี่ยนแปลงกำหนดการ เอกสาร หรือข้อมูลอื่น ๆ

## กำหนดการอาจเปลี่ยนแปลง
[กำหนดการ](02-agenda.md)ฝึกอบรมอาจมีการปรับเปลี่ยนตามความเหมาะสม โปรดติดตามประกาศล่าสุดในหน้านี้
