# การเตรียมตัวก่อนเดินทางมาร่วมอบรม

ข้อมูลทั้งหมดที่ผู้เข้าร่วมควรทราบและเตรียมพร้อม **ก่อนวันเดินทางมาอบรม**

## Checklist สิ่งที่ต้องทำ/เตรียม

### ก่อนการฝึกอบรม

- [ ] เข้าร่วม **ปฐมนิเทศออนไลน์** ก่อนการฝึกอบรม (17 กันยายน 2569 ผ่าน Zoom) — ชี้แจงโครงสร้างหลักสูตร เนื้อหาแต่ละหมวดวิชา และให้ผู้เข้าอบรมได้ทำความรู้จักกันก่อนล่วงหน้า
- [ ] ศึกษาและทำความเข้าใจวัตถุประสงค์ของหลักสูตร โครงสร้างหลักสูตร รายละเอียดแต่ละหมวดวิชา และแบบฟอร์มภาคปฏิบัติล่วงหน้า (ดู[กำหนดการ](02-agenda.md)) พร้อมยอมรับเงื่อนไข/หลักเกณฑ์ที่กำหนด โดยจะไม่มีข้อโต้แย้งในภายหลัง
- [ ] อ่าน[คู่มือสำหรับผู้เข้าร่วม](https://drive.google.com/file/d/1ov25KR5qf8WH0bShl9Bqz2Kgh7ch33Nx/view?usp=drive_link) ก่อนวันฝึกอบรม

### ระหว่างการฝึกอบรม

- [ ] เตรียม **คอมพิวเตอร์/Notebook** ส่วนตัวมาใช้ระหว่างการอบรม — หากไม่สามารถนำมาได้ ต้องแจ้งผู้จัดล่วงหน้าก่อนเริ่มการฝึกอบรม
- [ ] เข้าร่วม[กลุ่ม LINE](https://line.me/R/ti/g/HJtGkLN7G2) ของโครงการ (กลุ่มรวม) ใช้ติดต่อระหว่างผู้จัด วิทยากร ผู้เข้าอบรม และตัวแทน วช. — กลุ่มย่อยแยกตามสาขา รอข้อมูลเพิ่มเติม

  [![QR code กลุ่ม LINE](../assets/images/LineQR.jpg)](https://line.me/R/ti/g/HJtGkLN7G2)
- [ ] ตรวจสอบข้อมูลของตนเอง (ตำแหน่ง ชื่อ-สกุล หน่วยงาน เบอร์ติดต่อ อีเมล) ให้ถูกต้องในรายชื่อผู้มีสิทธิ์เข้ารับการฝึกอบรม เมื่อมีการประกาศ (ดู[ข้อมูลผู้เข้าอบรม](04-trainers.md))
- [ ] เข้าร่วมฝึกอบรมให้ครบตลอดระยะเวลา 5 วัน (28 ก.ย. – 2 ต.ค. 2569) โดยต้องได้รับการรับรองจากหัวหน้างานหรือหน่วยงานต้นสังกัด

## สถานที่จัดกิจกรรม

**วนาศรม มหาวิทยาลัยแม่ฟ้าหลวง** จังหวัดเชียงราย

ห้องประชุมที่ใช้ตลอดกิจกรรม:
- ห้องประชุมวนาสวรรค์ (พิธีเปิด/ปิด, บรรยายภาคทฤษฎีส่วนใหญ่)
- ห้องประชุมวนาทัศน์ (กิจกรรมกลุ่ม/ภาคปฏิบัติ)
- ลานอาหาร วนาศรม (มื้ออาหาร)
- ห้องพักวนาศรม (ที่พัก)

### การเดินทางมายังสถานที่จัดงาน
ผู้เข้าร่วมเดินทางมาเอง (ดูแผนที่ด้านบนประกอบการวางแผน) — รายละเอียดเพิ่มเติมถ้ามีจะแจ้งผ่านกลุ่มสื่อสารออนไลน์ของโครงการแทน

## ที่พัก
เข้าพักที่ห้องพักวนาศรม (ในพื้นที่จัดกิจกรรม) ตลอดการฝึกอบรม 28 ก.ย. – 2 ต.ค. 2569

## ค่าใช้จ่าย

- **ไม่มีค่าลงทะเบียน**
- มหาวิทยาลัยแม่ฟ้าหลวงสนับสนุน: อาหารกลางวัน อาหารเย็น และอาหารว่าง/เครื่องดื่ม (เช้า–บ่าย) ตลอดการอบรม
- **ผู้เข้ารับการฝึกอบรมรับผิดชอบเอง:** ค่าที่พัก, ค่าเดินทาง, ค่าใช้จ่ายอื่น ๆ
