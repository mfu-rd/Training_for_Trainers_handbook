# ข้อมูลผู้เข้าอบรม (Trainers)

> ยังไม่มีข้อมูล — จะทยอยอัปเดตเมื่อมีรายชื่อ/การจัดกลุ่มจากผู้จัด

เมื่อประกาศรายชื่อแล้ว ผู้เข้าอบรมทุกท่านควรตรวจสอบข้อมูลของตนเอง (ตำแหน่ง ชื่อ-สกุล หน่วยงาน เบอร์ติดต่อ อีเมล) ในรายชื่อผู้มีสิทธิ์เข้ารับการฝึกอบรมด้านล่างว่าถูกต้อง
