# เกี่ยวกับกิจกรรม

## ชื่อกิจกรรม
หลักสูตร **"วิทยากรเพื่อการพัฒนานักวิจัย" (Training for the Trainers - TFT)**

จัดโดย สำนักงานการวิจัยแห่งชาติ (วช.) ร่วมกับ มหาวิทยาลัยแม่ฟ้าหลวง

## วัตถุประสงค์
เพื่อพัฒนาศักยภาพนักวิจัยสู่การเป็นวิทยากรมืออาชีพ ครอบคลุม:
- ด้านการพัฒนาโจทย์วิจัย
- การออกแบบงานวิจัย
- การเขียนข้อเสนอการวิจัยเชิงบูรณาการ

## กลุ่มเป้าหมาย / ผู้เข้าร่วม
นักวิจัยที่มีรายชื่อในระบบ NRIIS และมีผลงานวิจัยตามเกณฑ์ วช. (หัวหน้าโครงการทุน FF หรือ PMUs, มีค่า H-index ในฐานข้อมูล Scopus ไม่น้อยกว่า 5, มีผลงานตีพิมพ์ในฐานข้อมูล Scopus)

ผู้เข้าอบรมแบ่งเป็น **7 กลุ่มสาขาวิชา**:
1. การวิจัยด้านวิศวกรรมศาสตร์
2. การวิจัยด้านเกษตรศาสตร์
3. การวิจัยด้านวิทยาศาสตร์ธรรมชาติ
4. การวิจัยด้านวิทยาศาสตร์การแพทย์และสุขภาพ
5. การวิจัยด้านสังคมศาสตร์
6. การวิจัยด้านมนุษยศาสตร์
7. การวิจัยเชิงบูรณาการ
